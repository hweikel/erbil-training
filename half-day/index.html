Curriculum introduction

Curriculum introduction

What is AI literacy?

  • Understanding how AI systems work, when they fail, and how to prepare students to use them
  • Not the same as technical knowledge or tool training
  • Thesis of this course: “Mastery before amplification”

Curriculum introduction

Curriculum outline

  • Kindergarten to Grade 6: five units per grade
  • Grades 7 to 9: the same six units every year — core concepts, data literacy, tools, ethics, project, presentation
  • One class every 1–2 weeks, depending on grade level

Curriculum introduction

How the curriculum changes over time

  • K–6 is unplugged, device-free — mostly games and projects
  • 7–12 is a mix of unplugged and tool-based lessons
  • The same themes reappear and build every year

Curriculum introduction

Policies

  • Staged tool use — K–6 is unplugged; Grade 7 onward, students use approved tools, supervised
  • Protect student data — no cameras, no personal accounts, no student data

Curriculum introduction

Assessment

  • Every lesson carries its own assessment
  • K–6: a short class-level check the teacher fills in afterwards. No student scores. No student accounts.

AI foundations

AI foundations

How do AI models work?

  • Training data and learning — shown examples, it finds the patterns
  • Statistical prediction of tokens — language is broken into small chunks, and the model predicts what comes next
  • Modalities — LLMs don’t truly understand math, images, etc; each is a different kind of information
  • Contemporary tools — context windows, harnesses and wrappers shape what a tool can do, separate from the model itself

AI failure modes

Hallucination & non-determinacy

  • Non-determinism: answers are based on probability, not truth
  • Hallucination: common data creates unexpected & untrue output

AI failure modes

Biased training data

  • Scraping targets what is freely available online, which is mostly English
  • All data is incomplete, so all models are biased
  • Attempts to fix these problems produce more problems

Name 3 scientists. Fast!

AI failure modes

AI detectors don’t work

  • False positives are constant
  • Second-language students are accused most often
  • The alternatives: clear standards, and grading the process instead of the output
Problem

Cognitive debt

  • Using an LLM during writing changes brain activation, reducing neural connectivity and sense of ownership
  • Comparisons to calculators and search engines are not accurate
  • Too early to know the long-term effect on developing minds

Kosmyna et al. (2025), MIT Media Lab · arXiv:2506.08872 · brainonllm.com

Solution

Cognitive debt

  • Staged tool use
  • Mastery before amplification

Student safety and development

Unsafe answers

  • Sycophancy and long conversations create psychological danger
  • Consumer chatbot protections do not work
  • Almost any mainstream tool can be broken with prompt injection

Interactive classrooms

What are interactive classrooms?

  • Structured activities that get every student thinking and speaking, not just listening
  • The teacher facilitates rather than lectures
  • Same core content, delivered through games, roles, and discussion

Interactive classrooms

Interactive classrooms

Classroom management

  • Structure!
  • Assign roles before you start, never during
  • Make groups & move desks
  • Set a visible timer
  • Several short rounds beat one long one
  • Keep it short — never let the whole lesson become one big activity

Project-based learning

Project-Based Learning

  • Projects give students structure to iterate on their work while learning course content
  • Project-based courses create continuity between classes

Project-based learning

Same format, every grade

  • Grade 9 — build sprint, second sprint, evidence and testing, revise with feedback, implementation plan, risk review, pitch, panel, peer review, reflection
  • Grade 5 — four lessons: classroom use case → student model card → build a fair training pack → showcase
  • K–6 has no long project. Each grade ends in one culminating task.

Microteaching

Microteaching

How it works

1

Break into small groups

2

Split a lesson into one part each — G2-03 or G3-03 work well

3

Each person teaches their part to the rest of the group — a shortened, ~25 minute version is fine

4

Other teachers act as students and try to find weaknesses

5

Exchange feedback, then teach it again with one improvement per section

Microteaching

Feedback

For each step, your peers share

  • One thing that worked
  • One thing to adjust

Then, as a group — classroom management

  • How would students “break” this lesson?
  • How can we add more structure to avoid that?
